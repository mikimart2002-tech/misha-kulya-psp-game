# Міша і Куля — PSP game

Піксельна романтична гра про знайомство Міші та Кулі біля магазину «Сімі».

## Що всередині

- вступна сцена та діалоги;
- QTE-мінігра на гітарі;
- поїздка до KFC з об’їздом ям;
- риболовля зі стіком;
- фінальний вибір, сердечка та титри.

Поточна версія — браузерна основа з ретро-піксельною візуальною мовою. Наступний крок — перенесення логіки та графіки на PSP homebrew з керуванням через D-pad, аналоговий стік і кнопки консолі.

## Запуск у workspace

Проєкт розрахований на вихідний pnpm workspace Replit. Основний ігровий код: src/App.tsx та src/index.css.
